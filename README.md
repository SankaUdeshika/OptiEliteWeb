# 🧾 OptiElite Web System

A full-stack **Invoice and Branch Billing Management System** built using **Node.js**, **Express.js**, and **MySQL**, with a responsive admin dashboard interface.

---

## 🚀 Features

- 🔐 Secure user login with sessions
- 🧍 Branch-based user management
- 💰 Real-time invoice tracking and daily sales reports
- 📊 Branch performance dashboard with cash collection summary
- 🧾 Invoice view and detail page with dynamic data
- 📅 Filter reports by date and month
- 🧠 MySQL backend with optimized queries and joins
- 💻 Bootstrap-based admin interface

---

## 🧩 Tech Stack

| Layer | Technology |
|--------|-------------|
| Backend | Node.js, Express.js |
| Frontend | HTML5, CSS3, JavaScript (ES6), Bootstrap |
| Database | MySQL |
| Sessions | express-session |
| Charts | Chart.js |
| Template | [Stisla Admin Template](https://getstisla.com/) (modified) |
